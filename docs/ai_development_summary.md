整理日期：2026-10-10。依据：根目录需求、用户实际阶段指令与反馈、[开发日志](ai_development_log.md)、[测试报告](test_report.md) 及本轮本地审查。本文是开发会话结束后的 Markdown 总结，不是编造的聊天逐字记录。

## 项目需求与目标

开发面向普通用户的简体中文 Windows 桌面视频格式转换器。支持 MP4、AVI、MOV、MKV、WEBM 导入，真实元数据和缩略图，格式转换、真实进度、取消、结果打开和本次运行记录。视频留在本机，不需要账户、云端或独立后端服务。

功能以根目录 [requirements.md](../requirements.md) 为唯一依据；UI 图只提供视觉参考，其视频、进度和历史不得作为真实业务数据。未纳入批量队列、质量/分辨率高级设置和历史持久化等可选增强功能。

本文按用户实际发起的三个开发阶段组织；需求文档原计划中的测试/交付工作在用户第三阶段任务中一并推进，不改写原需求的阶段划分。

## 技术方案的选择与调整

| 选择 | 决策来源与原因 |
| --- | --- |
| Electron + Vue 3 + Vite + Tailwind CSS | 用户明确指定，产品必须为 Windows 桌面 App |
| 主进程 / Preload / 渲染进程分层，IPC | 用户指定架构；AI 实现受限桥接、来源校验、隔离、沙箱和禁用 Node integration |
| child_process + FFmpeg/FFprobe CLI | 用户明确要求，无 Python/FastAPI/HTTP 服务，无 FFmpeg API 或 fluent-ffmpeg |
| 主进程与 Preload 用 CJS，Vue 用 ESM | AI 工程选择，减少额外主进程构建链，未声称用户逐项确认 |
| 组件拆分与 composable 管理状态 | AI 工程选择；未引入数据库、路由库或复杂调度器 |
| 固定编码参数、单任务锁、带 revision 状态快照 | AI 实现方式，对应用户“真实转换、安全调用、防重复提交和旧状态覆盖”的要求 |
| 同名编号、专属临时目录、等待进程关闭后清理 | AI 实现方式，落实保留原视频、避免覆盖和取消清理要求 |
| 开发可配置引擎，安装版只用 resources/ffmpeg | 从开发接入推进到用户要求的独立安装交付；保留开发便利性，安装版不依赖全局 PATH |
| 依赖精确锁定、镜像和项目盘构建缓存 | AI 根据实际网络超时、缓存跨盘失败采取的修复；不是开发者事先给定的依赖版本 |

主要版本：Electron 44.7.0、Vue 3.5.43、Vite 8.3.4、Tailwind 4.3.3、electron-builder 26.15.3、Playwright 1.64.0。视频引擎为 Gyan FFmpeg/FFprobe 9.0.2。第二、三阶段没有重新初始化工程或增加新的运行时依赖。

## 三个阶段的实际工作

### 阶段一：0.1.0 框架与中文界面

读取需求与参考图、检查环境并初始化工程，建立 Electron 窗口、Preload 白名单 IPC、Vue 页面、开发脚本和打包配置。实现侧栏、导入/信息区、转换设置、任务列表、记录和设置页，处理空/加载/错误/禁用状态。

这一阶段只读取真实文件基础属性，解析/缩略图/转换尚未接入时明确占位或禁用，没有伪造文件和转换进度。完成生产/开发页面测试和初步 NSIS 构建；当时未执行安装/卸载验收。用户随后反馈 PowerShell 脚本被拦截及启动无页面，修复启动文档和窗口显示问题。

### 阶段二：0.2.0 真实本地视频处理

按用户要求保留原布局，接入经过归档 SHA256 校验的 FFmpeg/FFprobe。完成信息解析、短视频缩略图、五种容器编码、真实进度、不确定进度、单任务取消、结果保存/打开及关闭确认。

通过参数数组执行子进程，输入/输出校验和主进程任务状态绑定真实界面。加入真实生成视频、完整解码、取消和异常测试，修复单帧 JPEG 色彩范围问题。用户明确要求该阶段不正式打包，执行中保留旧构建。

### 阶段三：0.3.0 产品细节、安装与交付验证

保留浅色/青绿卡片布局，调整窗口高度、主区域滚动、固定侧栏、紧凑任务行、长路径显示及友好容器名。配置应用图标、版本和 x64 中文 NSIS，将两个引擎置于包外 resources；安装版只从自身路径解析。

构建安装包并在源码外中文/空格目录实际安装、卸载重装，测试真实原生文件选择、双向转换、取消、退出清理、重启和快捷方式。整理许可证与构建信息，同时明确 GPL 对应源码材料缺口，未将候选包宣称为可公开合规分发。

## AI 辅助开发的具体方式

- 阅读和核对需求/现有代码/图片，把阶段边界落实到可用、禁用和错误状态。
- 编写 Electron、Vue、媒体服务、IPC、构建与测试脚本；通过实际执行发现问题后修正，不仅给出建议。
- 用 FFmpeg lavfi 创建合法样本，核对真实编码、进度、文件大小和全量解码；无随机进度或伪造任务。
- 使用 Playwright 操作真实 Electron，检查主/渲染进程通信和窗口；安装验收增加 Windows UI Automation 与限定控件的 Win32 操作。
- 查看实际截图、对照参考图调整细节；区分截图评审、自动化操作与用户人工播放反馈。
- 查询官方/供应方许可说明，记录二进制自身许可和配置；没有代替权利人选择整个项目许可证。
- 更新安装/使用说明、保留真实失败与修复记录，并在本轮生成总结和提交检查清单。
