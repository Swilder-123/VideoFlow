## 需求理解

完整读取根目录 `requirements.md`，查看 `前端UI图/现代中文视频转换器界面.png`。需求文档是唯一功能与验收依据，图片只指导布局、配色和组件样式。本阶段交付 Electron 客户端框架与界面，不实现视频解析与真实转换，不展示模拟任务、视频或进度。

## 技术选择及原因

- Electron 44.7.0、Vue 3.5.43、Vite 8.3.4、Tailwind 4.3.3、electron-builder 26.15.3；使用 registry 最新稳定版本元数据检查 Node engines 与插件 peerDependencies，并锁定版本。Vue 插件 6.0.10、Tailwind Vite 插件 4.3.3 均支持 Vite 8。
- Vue 渲染进程采用 ESM / 单文件组件；主进程与沙箱 Preload 使用 CommonJS，避免引入额外主进程打包链。
- 原生标题栏控件配合可拖动标题区域，减少自制窗口管理接口。
- 状态以 Vue ref/composable 管理，三个页面本地切换，无路由库或全局状态库。
- Tailwind Vite 插件处理工具样式，业务 CSS 负责参考图布局与响应式细节；线性图标为本地 SVG 组件，无外部图像请求。
- IPC 暴露专用接口，主进程限制发送窗口、主框架和页面 URL；启用上下文隔离、沙箱、CSP，关闭 Node integration，拒绝外部导航、新窗口和权限请求。
- 文件信息只读取文件系统属性，不将扩展名冒充 FFprobe 解析结果。
- Playwright 1.64.0 用于真实 Electron 窗口验证。测试系统对话框时仅替换其返回边界，文件校验与 IPC 均真实运行；使用 Chromium 文件拖拽事件验证 Preload 中 `webUtils.getPathForFile`。

官方 registry 经 Node 连接到 `103.73.220.188:443` 超时，而系统 curl 可以访问。使用 `--registry=https://registry.npmmirror.com` 完成 npm 安装，没有修改全局 registry。查询 curl 返回的官方 registry 元数据，核对锁定版本和兼容关系。

## 后续反馈：启动后没有可见窗口

用户反馈启动后没有页面。检查发现 Vite 端口 5173 正常返回 HTTP 200，Electron 主进程及渲染进程在运行，但 Windows `MainWindowHandle` 为 0、窗口标题为空。

实际做启动参数对照：原脚本使用 `windowsHide: true`，同一页面改用 `windowsHide: false` 后出现可见原生窗口，`MainWindowHandle` 为非零，标题为“VideoFlow 视频格式转换器”。因此将 `scripts/dev.mjs` 的交互式 Electron 子进程改为 `windowsHide: false`，并将终端提示改为服务就绪、窗口启动中，避免仅创建子进程就声称桌面启动完成。

此前测试使用 Playwright 直接启动 Electron，没有覆盖 `scripts/dev.mjs` 的 spawn 参数，这是前次验证遗漏。新增 `tests/dev-launcher.spec.js`，实际运行开发脚本，检查其 Electron 子进程的 Windows 可见窗口句柄和标题，并通过原生关闭操作确认启动器退出。首次新增测试遇到 Windows PowerShell 标准输出编码导致的中文标题乱码，显式设置 UTF-8 后修复。最终执行 `npm.cmd test`：3 passed（7.9 秒）。

### 实现与选择

- `electron/media/engines.cjs` 统一路径查找：显式环境变量、包外 resources/ffmpeg、项目 tools/ffmpeg/bin、PATH。显式错误路径不静默回退。启动时验证版本，设置页显示实际路径和缺失说明。
- `process.cjs` 使用无 shell 的 spawn、固定参数数组、输出上限、诊断尾部、超时和 AbortSignal。取消后等待 close 才执行临时文件清理，FFmpeg 作为后台工具隐藏其窗口；交互式 Electron 继续显示窗口。
- `service.cjs` 持有视频与单任务状态；解析首个非封面视频流，保留真实元数据。解析互斥，任务同步加锁，视频 ID 和文件 stat 校验避免旧文件/已修改文件被意外转换。
- 缩略图按实际时长取帧，失败降级占位。JPEG 读成有大小限制的 data URL 后清理专属临时目录；切换视频替换数据，不在渲染进程直接访问任意本地文件。
- `formats.cjs` 固定容器/视频/音频组合，兼容性优先；不通过改扩展名伪造转换。`-progress pipe:1` 的 out_time_us 按微秒解析，运行阶段最高 99%，未知时长保持 null，完成校验并安全保存后才 100%。
- 结果使用原名加 `_converted`，撞名递增编号。FFmpeg 输出到目标目录下专属随机临时目录，用不覆盖的硬链接发布（不支持硬链接时独占复制），失败/取消清理自建临时目录，不删除源视频。
- IPC 保留来源限制，增加移除视频、开始/取消任务、清记录和按任务 ID 打开结果；状态快照有递增 revision，订阅返回解绑函数。
- 现有信息区、预览区、按钮及任务表直接绑定真实状态，保留原布局。导航、历史页和设置页沿用原组件结构。
- 关闭活动转换时默认继续；明确选择取消并退出后终止子进程、清理并关闭。
